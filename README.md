# 鏡花ママの無料診断｜次に見る場所

「悪い人やないのに、一緒におると疲れる」相手について、次に見る場所を一つに絞る全8問の無料診断です。

## 公開方法（GitHub Pages）

1. GitHubで新しいリポジトリを作成する
2. このフォルダ内のファイルをリポジトリ直下へ入れる
3. `Settings` → `Pages` を開く
4. `Deploy from a branch`、`main`、`/(root)` を選んで保存する

公開後のURLは通常、`https://ユーザー名.github.io/リポジトリ名/` です。

## LINE導線

診断結果から公式LINEへ移動し、次のいずれかのキーワードを送る設計です。

- 待てるか
- 見てへん時
- 都合の悪い返事
- 引き方

公式LINE: https://lin.ee/8yc44Z8

## ファイル

- `index.html`: 画面と文章
- `styles.css`: デザイン
- `app.js`: 質問、結果、診断処理
